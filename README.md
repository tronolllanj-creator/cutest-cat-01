# cutest-cat-01

[![make.fun · cutest-cat-01](https://make.fun/badge/cutest-cat-01.svg)](https://make.fun/bounty/cutest-cat-01)

An irresistibly cute kitten: huge sparkling eyes, soft fluffy cream-and-ginger fur, tiny pink nose, head tilt. The program copies the image the repository holds to `/output/entry.png`, deterministically, with no network.
